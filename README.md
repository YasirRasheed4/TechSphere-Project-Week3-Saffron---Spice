# 🍲 Saffron & Spice — Authentic Pakistani Cuisine Landing Page

A complete, responsive landing page for a fictional Pakistani homemade food delivery service, built as part of the **TechSphere PK Virtual Internship (Web Development Track - Week 3)**.

---

## 📌 Project Overview

**Saffron & Spice** is designed to connect clients in Lahore with traditional, home-cooked Pakistani meals delivered daily. This project demonstrates modern responsive web design principles, structured semantic HTML5, modular CSS Grid layouts, basic SEO configurations, and light interactive JavaScript.

---

## ✨ Features & Required Sections

This landing page covers all **7 required business sections**:

1. **Hero Header:** Bold brand headline, short value proposition tagline, dual Call-to-Action (CTA) buttons, and full-cover background styling.
2. **About Section:** Brand story detailing authentic cooking methods, paired with an unsplash food preview image using a 2-column layout.
3. **Services (3 Cards):** Daily Meal Subscriptions, Event Catering, and Custom Party Packs using CSS Grid with interactive lift hover effects.
4. **Why Choose Us:** 4 key value propositions with Font Awesome iconography built inside a 2-column grid layout.
5. **Testimonials:** 3 realistic customer reviews featuring full star ratings (★★★★★).
6. **Contact Form:** Professionally styled input fields for name, email, phone number, and custom message inquiry.
7. **Footer:** Business tagline, social media links (Instagram, Facebook, WhatsApp), and copyright declaration.

---

## 🛠️ Technical Implementation & SEO

* **Semantic HTML5:** Native sections (`<header>`, `<section>`, `<footer>`, `<form>`) for enhanced accessibility.
* **CSS Grid & Flexbox:** Mobile-first responsive layouts using `display: grid` with `repeat()` functions.
* **SEO & Open Graph Meta Tags:**
  * Custom page `<title>` and `<meta name="description">`[cite: 1]
  * Open Graph social sharing tags (`og:title`, `og:description`, `og:type`)[cite: 1]
  * Dynamic emoji favicon implementation (`https://fav.farm/🍲`)[cite: 1]
* **Typography & Icons:** Embedded Google Fonts (**Volkhov** for titles, **Poppins** for body copy) and Font Awesome v6 icons.
* **Responsive Design:** Native CSS media queries targeting mobile (375px) and desktop (1200px) displays without horizontal scrolling.
